# GULABARI (गुलाबारी) — Jaipur

> **Authentic Sanganeri Hand Block Printed Luxury Fashion**  
> *Crafted with natural botanical dyes and hand-carved teakwood blocks on pure cotton in Sanganer & Jahota, Rajasthan.*

---

## 📌 Brand Essence & Overview

**GULABARI** bridges centuries-old Rajasthani courtly block printing techniques with contemporary luxury silhouettes. Every garment is stamped block-by-block with unhurried rhythmic pressure by hereditary master artisans of the Chippa community, utilizing unbleached cotton mul, cambric, and organic botanical dye extracts (madder, indigo, pomegranate rind, and iron rust).

The platform serves as an immersive digital flagship showcasing authentic hand-block collections with tactile fabric interactions, artisanal heritage stories, and a relational database architecture.

---

## ✨ Features

- **Heritage Aesthetics & Typography:** Custom editorial layout pairing Fraunces and Inter typography with authentic archival Rajasthani design motifs.
- **E-Commerce Craft Architecture:**
  - Full collection browser with filterable attributes for natural dye type, fabric weight, and traditional motif.
  - Interactive artisan documentary profiles and workshop photo essays.
  - Cart and wishlist drawers with persistent local client state.
  - Next.js server actions and API routes for customer inquiries and orders.
- **Relational Data Layer:** Type-safe database schema managed with Drizzle ORM connecting to PostgreSQL.
- **Fluid Motion Design:** Restrained, organic micro-interactions and transitions powered by Framer Motion.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router, React 19)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) & Editorial CSS Design Tokens
- **Database & ORM:** [Drizzle ORM](https://orm.drizzle.team/) + [PostgreSQL](https://www.postgresql.org/)
- **Motion:** [Framer Motion](https://www.framer.com/motion/)
- **Typography:** Fraunces & Inter

## 💻 Installation & Local Setup

### Prerequisites
- Node.js (v18.x or later)
- npm or yarn

### 1. Clone the Repository
```bash
git clone https://github.com/Hvsr1984/gulabari-sanganeri-fashion.git
cd gulabari-sanganeri-fashion
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Database Commands
```bash
npm run typecheck
```
