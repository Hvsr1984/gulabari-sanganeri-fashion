# GULABARI (गुलाबारी) — Jaipur

> **Authentic Sanganeri Hand Block Printed Luxury Fashion**  
> *Crafted with natural botanical dyes and hand-carved teakwood blocks on pure cotton in Sanganer & Jahota, Rajasthan.*

---

## ✦ Brand Essence

**GULABARI** bridges centuries-old Rajasthani courtly block printing techniques with contemporary luxury silhouettes. Every garment is stamped block-by-block with unhurried rhythmic pressure by hereditary master artisans of the Chippa community, utilizing unbleached cotton mul, cambric, and organic botanical dye extracts (madder, indigo, pomegranate rind, and iron rust).

---

## ✦ Architectural Features

- **Heritage Emblem & Typography**: Clean transparent cusped jharokha arch with botanical rose seal derived from authentic archival art.
- **Physical Luxury Animations**:
  - **Sanganeri Wooden Block Stamping**: Interactive block drop, fabric compression, lift, and pigmented botanical impression.
  - **Tactile Fabric Experience**: 3D perspective mouse depth simulation across unbleached cotton weaves.
  - **Botanical Rose Signature**: SVG path line-drawing stroke animation.
  - **Dynamic Navbar**: Transparent over editorial hero transitioning smoothly into warm ivory (`#F3EFE6`) on scroll.
  - **Matte Craft Pill Badges**: Strict physical editorial badges without artificial glows, halos, or neon bloom.
- **E-Commerce Craft Architecture**:
  - Full product browser with dye, fabric, and motif filtering.
  - Interactive artisan documentary profiles and workshop photo essays.
  - Cart and wishlist drawers with persistent local state.
  - Clean API routes for customer inquiries and newsletter subscriptions.

## ✦ Getting Started

### Prerequisites

- Node.js 18+ / 20+
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Hvsr1984/gulabari-sanganeri-fashion.git
cd gulabari-sanganeri-fashion

# Install dependencies
npm install

# Start development server
npm run dev

# Run typecheck
npm run typecheck

# Build for production
npm run build
```

## ✦ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Styling**: Tailwind CSS v4 & Custom Editorial CSS tokens
- **Typography**: Fraunces & Inter (Google Fonts)
- **Motion**: Framer Motion
- **Database / Schema**: Drizzle ORM (PostgreSQL)
